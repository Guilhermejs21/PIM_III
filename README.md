# LuminaTech – Plataforma Educacional

## Sobre o projeto

A LuminaTech é uma plataforma web educacional desenvolvida como parte do Projeto Integrado Multidisciplinar III (PIM III), do curso de Análise e Desenvolvimento de Sistemas da Universidade Paulista (UNIP).

O projeto tem como objetivo oferecer um ambiente digital de avaliação e apoio à aprendizagem, atendendo alunos, professores e administradores.

## Funcionalidades

### Aluno
- Cadastro e autenticação.
- Acesso ao painel de desempenho.
- Realização de questionários.
- Consulta de resultados e histórico de avaliações.

### Professor
- Criação e gerenciamento de questionários.
- Aplicação e encerramento de avaliações.
- Acompanhamento dos resultados.

### Administrador
- Cadastro e gerenciamento de usuários.
- Ativação e desativação de acessos.
- Visualização de relatórios.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- SQL Server (modelagem do banco de dados)
- C# (conceitos de programação orientada a objetos)
- Git e GitHub

## Banco de dados

O projeto apresenta a modelagem relacional utilizando as entidades Usuários, Cursos, Aulas, Avaliações, Progresso, Medalhas e Usuario_Medalhas.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do sistema web.
3. Execute o arquivo `index.html` em um navegador.
4. Utilize as contas de demonstração disponibilizadas na tela de entrada.

## Observações

Esta versão é um protótipo demonstrativo. Os dados são armazenados no localStorage do navegador, sem integração com servidor ou banco de dados externo.
